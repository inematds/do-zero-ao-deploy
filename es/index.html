Para quién es este curso

Este curso es para ti si:

  • ✓ Nunca has abierto una terminal en tu vida
  • ✓ ¿Quieres publicar un sitio, pero no sabes por dónde empezar
  • ✓ Has oído hablar de Git, Docker y VPS, pero nunca los has usado
  • ✓ ¿Quieres tener tu propio servidor y dejar de depender de terceros
  • ✓ ¿Quieres crear un asistente personal con IA

Este curso NO es para ti si:

  • ✗ Ya tienes experiencia como desarrollador y dominas DevOps
  • ✗ Buscas un curso avanzado de Kubernetes
  • ✗ ¿Quieres aprender un lenguaje de programación a fondo
  • ✗ Esperar la certificación profesional
