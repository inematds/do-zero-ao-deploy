💻 La terminal: tu primer comando

La terminal es la ventana de texto donde hablas directamente con la computadora. Sin menús ni clics. Solo tú y la máquina. Aquí aprenderás a usar este superpoder.

1

Qué es la terminal

Piensa en la terminal como un chat con la computadora. En vez de hacer clic en íconos y menús, escribes comandos en texto y la computadora responde. Es como enviar un mensaje por WhatsApp, pero a tu máquina. Escribes "lista los archivos" y los lista. Escribes "crea una carpeta" y la crea.

🧠 Analogía: el terminal es un chat

Imagina que tienes un asistente muy obediente. No entiende gestos ni clics. Pero si escribes exactamente lo que quieres, lo hace de inmediato. Ese asistente es la terminal.

  • •Escribes: un comando (por ejemplo: ls)
  • •Responde: el resultado (la lista de archivos)
  • •Lo escribes de nuevo: otro comando
  • •Y así sucesivamente. Cada línea es un "mensaje".

💡 Nombres diferentes, lo mismo

Vas a escuchar varios nombres: Terminal, Símbolo del sistema, CMD, PowerShell, Shell, Console. Todos son variantes de la misma idea: una ventana de texto para comunicarte con la computadora. En Mac y Linux, lo más común es Terminal (con Bash o Zsh). En Windows, es el símbolo del sistema (CMD) o PowerShell.

2

Abrir la terminal en tu computadora

El primer paso es encontrar y abrir la terminal. Cada sistema operativo tiene el suyo, pero todos funcionan de la misma manera: tú escribes y la computadora responde.

W

Windows

Dos terminales disponibles: CMD (antiguo) y PowerShell (moderno)

# Opción 1: Presiona las teclas juntas

Windows + R, escribe "cmd", Enter

# Opción 2: menú Inicio

Menú Inicio > escribe "PowerShell" > haz clic

# Opción 3: Clic derecho en la carpeta

Shift + clic derecho > "Abrir ventana de comandos aquí"

Recomendación: Usa PowerShell. Acepta los mismos comandos que CMD y más.

🍎

macOS

La terminal ya viene instalada

# Opción 1: Spotlight

Cmd + Space, escribe "Terminal", Enter

# Opción 2: Finder

Aplicaciones > Utilidades > Terminal

🐧

Linux

La terminal es nativa y, normalmente, se accede a ella mediante un atajo

# Atajo universal

Ctrl + Alt + T

# O busca en las aplicaciones

Menú > Terminal (o Konsole, GNOME Terminal)

👁 Qué vas a ver al abrirlo

# En Mac/Linux, algo así:

usuario@meu-computador ~ $

# En Windows CMD:

C:\Users\SeuNome>

# En Windows PowerShell:

PS C:\Users\SeuNome>

O $ (o > en Windows) y es la señal de que la terminal está esperando que escribas. Es como el cursor parpadeante en un cuadro de texto.

⚠️ Error común

Problema: "Abrí la terminal y se cerró sola."
Solución: Esto ocurre cuando haces doble clic en un archivo .bat o .sh por error. El terminal abierto con los métodos anteriores queda esperando tus comandos. Si lo cerraste, ábrelo de nuevo con el método de tu sistema operativo.

3

Navegar por las carpetas: cd, ls, pwd

En el explorador de archivos, haces clic en las carpetas para entrar. En la terminal, haces lo mismo con comandos. Piensa en la terminal como un explorador de archivos ciego: solo sabe dónde está si se lo preguntas, y solo va adonde tú le indicas.

pwd - ¿Dónde estoy?

"Print Working Directory". Muestra la ruta completa de donde estás ahora.

$ pwd

/home/usuario

En Windows, el equivalente es cd (sin argumentos).

ls - ¿Qué hay aquí?

"List". Muestra todos los archivos y carpetas del directorio actual.

$ ls

Desktop Documents Downloads Music Pictures

# Con más detalles:

$ ls -la

total 20

drwxr-xr-x 5 usuario usuario 4096 jun 16 10:00 .

drwxr-xr-x 3 root root 4096 jun 15 09:00 ..

drwxr-xr-x 2 usuario usuario 4096 jun 16 10:00 Desktop

-rw-r--r-- 1 usuario usuario 220 jun 15 09:00 .bashrc

En Windows CMD, el equivalente es dir. En PowerShell, ls funciona.

cd - Ir a otra carpeta

"Change Directory". Cambia a una carpeta diferente.

# Entrar en la carpeta Documents

$ cd Documents

$ pwd

/home/usuario/Documents

# Volver una carpeta atrás

$ cd ..

$ pwd

/home/usuario

# Ir directamente a la carpeta home

$ cd ~

# Ir a una ruta específica

$ cd /home/usuario/Documents/projetos

💡 Consejo: autocompletado con Tab

Al escribir nombres de carpetas o archivos, presiona la tecla Tab para autocompletar. Por ejemplo, escribe cd Doc y presiona Tab. El terminal completa hasta cd Documents/. Esto evita errores al escribir y ahorra tiempo.

✓ Qué HACER

  • ✓Usar pwd siempre que te pierdas
  • ✓Usar Tab para autocompletar nombres
  • ✓Usar cd .. para volver

✗ Qué NO hacer

  • ✗Escribir rutas enormes sin Tab
  • ✗Ignorar los mensajes de error ("No such file")
  • ✗Usar espacios en los nombres de las carpetas (complica todo)
4

Crear y manipular archivos

Ahora que sabes moverte por las carpetas, es hora de crear, copiar, mover y borrar cosas. En el explorador de archivos, usas clic derecho > "Nueva carpeta". En la terminal, escribes un comando y listo.

mkdir - Crear una carpeta

# Crear una carpeta llamada "meu-projeto"

$ mkdir meu-projeto

$ ls

meu-projeto

# Crear carpetas dentro de carpetas de una vez

$ mkdir -p meu-projeto/src/componentes

touch - Crear un archivo vacío

# Crear un archivo llamado "index.html"

$ touch index.html

$ ls

index.html

# Crear varios archivos de una vez

$ touch index.html style.css script.js

En Windows, usa echo. > index.html o New-Item index.html en PowerShell.

Copiar, mover y borrar

# cp = copiar (origen, destino)

$ cp index.html backup.html

# mv = mover (también sirve para renombrar)

$ mv backup.html pasta-backup/

$ mv arquivo-velho.txt arquivo-novo.txt

# rm = eliminar (CUIDADO: ¡no va a la papelera!)

$ rm arquivo-inutil.txt

# rm -r = eliminar la carpeta y todo lo que contiene

$ rm -r pasta-antiga

⚠️ CUIDADO con rm

El comando rm borra definitivamente. No hay papelera ni Ctrl+Z. Antes de ejecutar rm -r, verifica tres veces que la ruta sea correcta. Nunca ejecuta rm -rf / (eso borra TODO en la computadora).

📁
mkdir

Crear carpeta

📄
touch

Crear archivo

📋
cp / mv

Copiar / Mover

🗑
rm

Borrar (¡cuidado!)

5

Editores: nano y VS Code

Crear un archivo vacío es fácil. Pero ¿cómo ponerle contenido? Tienes dos opciones: editar directamente en la terminal (con nano) o abrirlo en un editor visual (como VS Code). Ambas formas funcionan. La elección depende de la situación.

📝 nano: Editor dentro de la terminal

# Abrir o crear un archivo con nano

$ nano index.html

nano se abre dentro del propio terminal. Escribes normalmente. En la parte inferior aparecen los atajos:

GNU nano 7.2 index.html

<html>

<body>Hola mundo</body>

</html>

^O Guardar ^X Salir ^K Cortar ^U Pegar

^O = Ctrl+O (guardar) | ^X = Ctrl+X (salir) | El ^ significa la tecla Ctrl.

VS Code: Editor visual al que se accede desde la terminal

Si tienes VS Code instalado, puedes abrir cualquier archivo o carpeta directamente desde la terminal:

# Abrir un archivo específico en VS Code

$ code index.html

# Abrir toda la carpeta como proyecto

$ code .

El punto . significa "carpeta actual". Esta es la forma más común de abrir proyectos en VS Code.

✓ Usa nano cuando

  • ✓Necesitas editar algo rápido (1-2 líneas)
  • ✓Está en un servidor remoto (SSH)
  • ✓Necesitas editar archivos de configuración

💻 Usa VS Code cuando

  • ✓Vas a trabajar en un proyecto completo
  • ✓¿Quieres resaltado de sintaxis (colores en el código)
  • ✓¿Quieres autocompletado y extensiones

Ejercicio: arma tu primer proyecto

Es hora de practicar todo junto. Vas a crear la estructura de carpetas de un proyecto web usando solo la terminal. Al final, tendrás un árbol de carpetas y archivos listo para empezar a programar.

🎯 Lo que vas a construir

meu-site/

├── index.html

├── style.css

├── script.js

├── img/

│ └── logo.png

└── pages/

├── sobre.html

└── contato.html

Paso 1: Crea la carpeta del proyecto

$ mkdir meu-site

$ cd meu-site

$ pwd

/home/usuario/meu-site

Paso 2: Crea los archivos de la raíz

$ touch index.html style.css script.js

$ ls

index.html script.js style.css

Paso 3: Crea las subcarpetas y sus archivos

$ mkdir img pages

$ touch img/logo.png

$ touch pages/sobre.html pages/contato.html

Paso 4: Revisa la estructura

$ ls -R

.:

img index.html pages script.js style.css

./img:

logo.png

./pages:

contato.html sobre.html

Paso 5: Agrega contenido a index.html

$ nano index.html

# Escribe esto dentro de nano:

<!DOCTYPE html>

<html>

<head><title>Mi sitio</title></head>

<body>

<h1>¡Hola, mundo!</h1>

</body>

</html>

# Ctrl+O para guardar, Enter, Ctrl+X para salir

🏆 ¡Felicitaciones!

Si pudiste crear toda esta estructura sin salir de la terminal, ya dominas los comandos fundamentales. A partir de ahora, usarás esos mismos comandos en todos los próximos módulos. En el siguiente, aprenderás a guardar versiones de tu trabajo con Git.
