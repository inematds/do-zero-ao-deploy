🏠 O Que e um VPS?

VPS significa Virtual Private Server (Servidor Virtual Privado). Pense assim: voce aluga um computador que fica em um datacenter, funcionando 24 horas por dia. E como ter um PC remoto, so seu, que nunca desliga. Enquanto o Vercel e o GitHub Pages rodam seu site "pra voce" (voce nao ve o servidor), com um VPS voce tem controle total: instala o que quiser, configura como quiser, roda o que quiser.

🔑 Analogia: Aluguel de Apartamento

Hospedar um site na Vercel e como morar em hotel: tudo incluso, mas voce nao muda nada. Um VPS e como alugar um apartamento:

  • •Voce escolhe o tamanho (RAM, CPU, disco) como escolhe quantos quartos
  • •Voce decora como quiser (instala programas, configura o sistema)
  • •Voce paga aluguel mensal (geralmente $3 a $20/mes)
  • •Voce tem a chave (acesso root, controle total)

💡 Quando usar um VPS?

Use VPS quando precisar rodar bots (Telegram, Discord), bancos de dados proprios, APIs customizadas, ou qualquer coisa que precisa ficar online 24h. Se voce so quer um site estatico, Vercel/Pages resolvem. Se precisa de controle total, VPS e o caminho.

Conceitos-chave

  • • VPS = computador virtual alugado
  • • Roda 24/7 em um datacenter
  • • Voce tem acesso root (admin total)
  • • Isolado de outros usuarios

Vocabulario

  • • Root = usuario administrador
  • • Datacenter = predio com servidores
  • • vCPU = processador virtual
  • • SSD = disco rapido

🏪 Provedores: Onde Alugar

Existem dezenas de empresas que alugam VPS. As tres mais populares para iniciantes sao DigitalOcean, Hetzner e Contabo. Cada uma tem seus pontos fortes. Vamos comparar para voce escolher.

🌊

DigitalOcean

A mais famosa. Interface bonita, docs excelentes.

Preco: a partir de $4/mes (1GB RAM, 1 vCPU, 25GB SSD)

Datacenters: EUA, Europa, Asia, Australia

Ponto forte: documentacao incrivel, comunidade grande

Pra quem: iniciantes que querem docs bons

🇩🇪

Hetzner

Alema, preco imbativel na Europa.

Preco: a partir de EUR 3.29/mes (2GB RAM, 1 vCPU, 20GB SSD)

Datacenters: Alemanha, Finlandia, EUA

Ponto forte: melhor custo-beneficio, hardware potente

Pra quem: quem quer mais por menos

💪

Contabo

Muito barato, mas interface mais antiga.

Preco: a partir de EUR 4.50/mes (4GB RAM, 2 vCPU, 50GB SSD)

Datacenters: Alemanha, EUA, Asia, Australia

Ponto forte: MUITO recurso por pouco dinheiro

Pra quem: quem precisa de mais RAM/disco barato

🛒 Contratando Seu Primeiro VPS

Vamos contratar um VPS na Hetzner passo a passo (o processo e similar nos outros provedores). Em 5 minutos voce tera seu servidor rodando.

Passo a Passo: Hetzner Cloud

  1. 1
    Criar conta: acesse hetzner.com/cloud e clique em "Register". Use email real (precisam verificar).
  2. 2
    Criar projeto: no dashboard, clique em "+ New Project". Nomeie "meu-servidor" ou algo parecido.
  3. 3
    Add Server: dentro do projeto, clique "Add Server". Escolha:
    • • Location: Nuremberg ou Helsinki (Europa) ou Ashburn (EUA)
    • • Image: Ubuntu 24.04 (a mais usada)
    • • Type: CX22 (2 vCPU, 4GB RAM) por EUR 3.29/mes
  4. 4
    SSH Key (opcional agora): pule por enquanto. No proximo modulo vamos configurar SSH direito.
  5. 5
    Create & Buy: clique no botao. Em ~30 segundos seu servidor estara rodando. Voce recebera a senha root por email.

⚠️ Erro Comum

Problema: "Nao recebi o email com a senha root"

Solucao: Verifique a pasta de spam. Se nao chegar em 5 minutos, use o console web do provedor (tem um botao "Console" no dashboard) para resetar a senha.

O que voce vai ter

  • • Um IP publico (ex: 168.119.xxx.xxx)
  • • Acesso root (admin total)
  • • Ubuntu 24.04 instalado
  • • Servidor rodando 24/7

Informacoes importantes

  • • Anote o IP do servidor
  • • Guarde a senha root em local seguro
  • • Lembre do datacenter escolhido
  • • Saiba o nome do projeto

🖥️ Primeiro Acesso: Console Web

Antes de configurar SSH (proximo modulo), voce pode acessar seu servidor pelo console web do provedor. E como ter um monitor e teclado plugados no servidor, so que no navegador.

Como acessar o Console Web (Hetzner)

  1. 1. Va ao dashboard Hetzner Cloud
  2. 2. Clique no nome do seu servidor
  3. 3. No menu lateral, clique em "Console"
  4. 4. Uma tela preta vai aparecer no navegador
  5. 5. Digite o login e senha:

login:

root

Password:

(digite a senha que recebeu por email - nao aparece na tela)

root@meu-servidor:~#

Quando voce ve o root@meu-servidor:~#, esta dentro! O # no final indica que voce e root (administrador).

💡 Dica: Primeira coisa a fazer

Assim que entrar, rode este comando para ver informacoes do sistema:

$ hostnamectl

Static hostname: meu-servidor

Icon name: computer-vm

Operating System: Ubuntu 24.04 LTS

Kernel: Linux 6.8.0-xx-generic

Architecture: x86-64

⚠️ Erro Comum

Problema: "Digitei a senha e nada acontece"

Solucao: No Linux, quando voce digita uma senha, NADA aparece na tela (nem asteriscos). Isso e normal e e por seguranca. Continue digitando e aperte Enter.

🐧 Linux no Servidor: O Basico

Seu VPS roda Ubuntu, uma versao do Linux. Nao se assuste: voce nao precisa ser expert. Vamos aprender os comandos essenciais para sobreviver no servidor. E como aprender as 20 palavras mais usadas de uma lingua nova.

Comandos Essenciais

# Onde estou?

$ pwd

/root

# Listar arquivos

$ ls -la

total 28

drwx------ 4 root root 4096 Jun 16 10:00 .

-rw-r--r-- 1 root root 3106 Jun 16 10:00 .bashrc

# Ver uso de disco

$ df -h

Filesystem Size Used Avail Use% Mounted on

/dev/sda1 20G 2.1G 17G 11% /

# Ver uso de memoria

$ free -h

total used free

Mem: 1.9Gi 180Mi 1.5Gi

# Ver processos rodando

$ htop

(abre um monitor interativo - aperte q para sair)

✓ O que FAZER

  • ✓Criar um usuario pessoal (nao usar root pra tudo)
  • ✓Anotar os comandos que usa com frequencia
  • ✓Usar Tab para auto-completar

✗ O que NAO fazer

  • ✗Rodar rm -rf / (apaga TUDO)
  • ✗Usar root como usuario do dia-a-dia
  • ✗Ignorar mensagens de erro (leia sempre!)

Criando um Usuario Pessoal

# Criar usuario (substitua "nick" pelo seu nome)

$ adduser nick

Adding user 'nick' ...

New password: (digite uma senha forte)

# Dar poderes de admin (sudo)

$ usermod -aG sudo nick

# Testar: trocar para o novo usuario

$ su - nick

nick@meu-servidor:~$

# Agora voce e "nick" (note: $ no final, nao #)

🔄 Atualizacao e Manutencao

Assim como seu celular recebe atualizacoes, seu servidor tambem precisa. Manter o sistema atualizado e a coisa mais importante que voce pode fazer pela seguranca do servidor. E como trancar a porta de casa antes de dormir.

Atualizando o Sistema

# 1. Atualizar lista de pacotes disponiveis

$ sudo apt update

Hit:1 http://archive.ubuntu.com/ubuntu noble InRelease

Get:2 http://archive.ubuntu.com/ubuntu noble-updates InRelease

Reading package lists... Done

15 packages can be upgraded.

# 2. Instalar as atualizacoes

$ sudo apt upgrade -y

Reading package lists... Done

Upgrading... Done.

# 3. (Opcional) Reiniciar se o kernel foi atualizado

$ sudo reboot

💡 Rotina de Manutencao

Faca isso pelo menos 1x por semana:

  1. 1. sudo apt update && sudo apt upgrade -y
  2. 2. sudo apt autoremove -y (remove pacotes orfaos)
  3. 3. df -h (verificar espaco em disco)
  4. 4. free -h (verificar memoria)

No Modulo 4.4 (Cron) voce vai aprender a automatizar isso.

Instalar Ferramentas Uteis

# Instalar tudo de uma vez:

$ sudo apt install -y htop curl wget git nano ufw

# O que cada um faz:

htop - monitor de processos (visual)

curl - fazer requisicoes HTTP

wget - baixar arquivos

git - controle de versao

nano - editor de texto simples

ufw - firewall (vamos usar no modulo 3.3)

Conceitos-chave

  • • apt = gerenciador de pacotes
  • • sudo = rodar como admin
  • • update = atualizar lista
  • • upgrade = instalar atualizacoes

Frequencia

  • • Atualizacoes: 1x por semana
  • • Check disco: 1x por semana
  • • Reboot: so quando necessario
  • • Backups: diarios (veremos em Cron)
